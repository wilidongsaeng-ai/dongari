# 방 탈출 추격 게임

복도를 따라 흩어진 방을 탐색하고, 코인을 모아 탈출구(포탈)를 찾아 탈출하는 추격형 방 탈출 게임입니다. 모든 코인을 모으면 포탈을 통해 보스전에 진입할 수 있습니다.

단일 HTML 파일(`index.html`)로 동작하는 순수 HTML/JS/Canvas 구현입니다. 별도 빌드나 서버 설치 없이 브라우저에서 바로 실행됩니다.

## 구현된 기능

- 스테이지별로 절차적으로 생성되는 맵 (복도 + 독립된 방 + 문)
- WASD 이동, E 상호작용(문 열기/닫기, 퀴즈 풀기, 포탈 진입)
- 코인 자동 획득, 수학 퀴즈 보상(속도/시야차단/방패 아이템)
- 추격 개체(고양이)의 시야/인식/추적 AI
- 보스전: 검사/궁수/마법사 직업 선택, 상점에서 무기·방어구·물약 구매
- 1~50 스테이지 난이도 곡선 (맵 크기, 적 속도, 보스 스탯 등)

## 실행 방법

`index.html`을 브라우저로 바로 열면 됩니다.

```bash
open index.html        # macOS
# 또는 로컬 서버로 실행
python3 -m http.server 4173
# 이후 브라우저에서 http://localhost:4173/index.html 접속
```

## 조작

| 키 | 동작 |
|---|---|
| WASD | 이동 |
| E | 문 열기/닫기 · 퀴즈 풀기 · 포탈 진입 |
| 1 | 속도 증가 아이템 사용 |
| 2 | 시야 차단(적) 아이템 사용 |
| 3 | 방패 아이템 확인(보유 시 자동 발동) |
| 마우스 클릭 | 보스전 공격 |

## 맵 구조

방들은 서로 직접 연결되지 않습니다. 넓은 복도 네트워크를 따라 방이 띄엄띄엄 배치되며, 각 방은 복도와 연결된 **문 1개**만 가집니다. 스테이지 번호가 시드가 되어, 같은 스테이지는 항상 같은 맵으로 생성됩니다.
